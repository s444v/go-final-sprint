
# 📝 Todoist Web Server

Это итоговый проект курса **"Go-разработчик с нуля" от Яндекс Практикум**.  
Приложение представляет собой **web-сервер** для сервиса **Todoist** — системы управления задачами.  

Сервер позволяет добавлять задачи, редактировать их, применять повторения, фильтровать по поисковым запросам и работать с задачами через веб-интерфейс.

---

## 🚀 Возможности

- ➕ Добавление задач
- ✏️ Редактирование задач
- 🔍 Поиск по задачам
- ♻️ Поддержка повторений задач (ежедневно, еженедельно, ежемесячно, ежегодно)
- 🔐 Аутентификация через пароль и JWT
- 🌐 Отдача HTML/JS/CSS из директории `web/`
- 🗄️ Хранение задач в SQLite

---

## 🌟 Выполненные задания со звёздочкой

✅ **1. Возможность определять путь к файлу базы данных через переменную окружения**  
✅ **2. Возможность определять порт извне через переменную окружения**  
✅ **3. Поддержка правил повторения `w` (еженедельно), `m` (ежемесячно)**  
✅ **4. Фильтрация задач по строке поиска**  
✅ **5. Аутентификация с использованием JWT и пароля из переменной окружения**  
✅ **6. Создан Docker-образ и опубликован в Docker Hub**
